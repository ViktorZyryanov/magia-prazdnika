# Магия праздника

Статический сайт для GitHub Pages. Сборка и сервер не нужны. Заявки уходят в Google Таблицу через Google Apps Script.

## Состав

- `index.html` — сайт.
- `apps-script/Code.gs` — код приёма заявок для Google Apps Script.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.
- `images/service-1.jpg` … `service-4.jpg` — фотографии четырёх услуг.
- `images/gallery-1.jpg` … `gallery-16.jpg` — предоставленные фотографии в перемешанном порядке (включая корпоративное фото).
- `images/qr-vk.png` — QR на группу VK. `images/qr-max-contact.png` — **контактная карточка с номером для MAX**, не прямая ссылка в чат.

## 1. Обновите Apps Script (обязательно)

Для расчёта скидки по фактической дате поступления заявки и записи новых столбцов обновите развёртывание Apps Script. Даже если прежний `/exec` отвечает `{"ok":true}`, без обновления скрипта новые поля и пересчёт на стороне Google могут не сохраниться:

1. Откройте Google Таблицу, куда должны приходить заявки, затем **Расширения → Apps Script**.
2. Удалите весь старый код и вставьте содержимое файла `apps-script/Code.gs`. Нажмите **Сохранить**.
3. **Развернуть → Управление развёртываниями** → значок карандаша у текущего развёртывания → **Версия: Новая версия** → **Выполнять как: Я** → **У кого есть доступ: Все** → **Развернуть**. При запросе разрешите доступ к таблице.
   Так адрес `/exec` не изменится и на сайте ничего менять не нужно. Если вы создадите **новое** развёртывание, адрес станет другим: тогда замените его в `index.html` в строке `const LEAD_ENDPOINT = "...";`.
4. Откройте адрес `/exec` в браузере. Должен появиться ответ вида `{"ok":true,"sheet":"Заявки",...}`.

Скрипт создаёт лист «Заявки» и лист «Лог» для ошибок. К прежним 13 столбцам **после `leadId`** добавляет «Район», «Населённый пункт», «Доплата за выезд», «Количество детей» и «Надбавка за дату и время», не сдвигая старые заявки. Повторная отправка одной и той же заявки не создаёт дубль. Если ваш текущий скрипт подключён к другой таблице, откройте именно ту таблицу, к которой привязан развернутый веб-скрипт.

## Сезонные даты и расчёт стоимости

- Календарь принимает заказы только с **20 по 31 декабря** ближайшего сезона. После выбора даты доступны только часы начала визита, разрешённые для этого дня.
- Базовая цена формата складывается с доплатой за детей (по 500 ₽ за каждого сверх трёх), пригород (+1 000 ₽) и сезонной надбавкой:
  - **20–29 декабря:** 10:00–18:00 — без сезонной надбавки; старты 19:00, 20:00 и 21:00 — +600 ₽.
  - **30 декабря:** старты 10:00–15:00 — +500 ₽; 16:00–22:00 — +1 100 ₽.
  - **31 декабря:** старты 10:00–15:00 — +1 200 ₽; 16:00–19:00 — +2 500 ₽; 20:00–21:00 — +3 700 ₽; в 22:00 — +6 500 ₽; в 23:00 — +7 500 ₽ (последний старт — до полуночи).

## Квиз и стоимость

В квизе под выбором формата приведены краткие описания всех четырёх услуг. «Подарок» — короткое поздравление, вручение подарка, хоровод, стих/песня и фотографии. «Дед Мороз на дом» включает «Подарок», игры и конкурсы. «Интерактив» включает формат «на дом» и проходит как мини-спектакль. «Корпоратив» включает утренники, школьные и производственные праздники и встречи компаний от 8 до 30 человек.

При выборе корпоратива можно указать взрослых, детей либо смешанную группу; общее число гостей — от 8 до 30. Базовая стоимость **5 500 ₽** включает до 12 взрослых или до 12 детей; каждый взрослый сверх 12 — **+300 ₽**, каждый ребёнок сверх 12 — **+200 ₽**. Если на корпоративе присутствуют и взрослые, и дети, первые 12 гостей считаются вместе и включены в базовую цену; за каждого дополнительного гостя +500 ₽ независимо от возраста. Доплаты за дату и пригород сохраняются.

**Ранняя скидка 10%** действует для заявок, поступивших до **1 декабря 2026 года** по времени Нижнего Тагила (до конца 30 ноября). Скидка применяется только к базовой стоимости формата: 250/350/450/550 ₽ в зависимости от выбранной услуги. Из итоговой суммы вычитается скидка; доплаты за время, выезд и участников не уменьшаются. Сайт показывает её в анкете и учитывает в квизе. Apps Script проверяет время поступления заявки и пересчитывает стоимость на своей стороне.

Выбранный формат в квизе — строгое условие. При ограниченном бюджете показываются все его доступные часы в пределах суммы; при «Готовы рассмотреть варианты» — все часы на выбранную дату и время суток. Другие детские услуги отображаются только при явном выборе «Подберите формат под мои пожелания». Если совпадений нет, квиз предложит изменить параметры. Кнопка «Подставить в заявку» переносит выбранные параметры; затем заказчику остаётся проверить данные, добавить имя и телефон и отправить заявку.

После обновления `apps-script/Code.gs` он добавит в конце листа «Заявки» столбцы **«Взрослых (корпоратив)»**, **«Детей (корпоратив)»**, **«Доплата за гостей»**, **«Скидка за ранний заказ»**, **«Стоимость до скидки»**, **«Базовая цена формата»**, **«Доплата за детей в детском формате»**, **«Итог числом»** и **«Правило тарифа»**. Отдельный лист **«Стоимость форматов»** содержит таблицу четырёх вариантов праздника с базой, лимитами, доплатами за часы, пригород и ранней скидкой. Прежние столбцы, включая «Стоимость» (итоговая с учётом скидки) и «Надбавка за дату и время», остаются на местах. Не создавайте новые столбцы вручную: обновите *текущее* развёртывание веб-приложения, чтобы сохранить адрес `/exec`, затем отправьте пробную заявку и проверьте строку в таблице.

## 2. Проверьте отправку

1. Откройте опубликованный сайт по адресу `https://...` (не двойным кликом по файлу).
2. Отправьте тестовую заявку **с телефона** и проверьте новую строку в листе «Заявки»: время в формате `18:00`, район и доплата должны сохраниться. Также проверьте итоговую цену и столбец «Надбавка за дату и время». Удалите тестовую строку. Если запись не подтверждена, сайт не показывает экран успеха и предлагает скопировать заявку для отправки в чат VK.
3. Проверяйте запись тестовой заявки в таблицу **после** обновления Apps Script; без доступного `/exec` невозможно надёжно подтвердить поступление заказа.
4. Публичная страница **больше не содержит** панели диагностики: её нельзя открыть кликами по логотипу, через `?debug=1` или другим скрытым способом. Для проверки используйте адрес `/exec` и одну тестовую заявку, затем проверьте строку в таблице.

## 3. Перед публикацией

1. Город Нижний Тагил и номер +7 (922) 114-65-32 уже добавлены. При изменении номера обновите `SITE_CONTENT.meta.phone`, `phoneHref`, QR для MAX и текст подсказки в футере.
2. Проверьте цены четырёх форматов в `SITE_CONTENT.services`: для пригорода сайт автоматически добавляет **1 000 ₽**. В форме только часы `10:00`–`23:00` и `00:00` (следующий день); поле района обязательно, а населённый пункт обязательно для пригорода.
3. Фото форматов и все 16 фотографий галереи уже находятся в `images/`. Фото первого экрана `hero-bg.jpg` пока не предоставлено, его можно добавить позднее; без него отображается декоративный фон.
4. QR с подписью MAX **сохраняет номер телефона в контакты**. Чтобы QR открывал непосредственно ваш чат, поделитесь из своего профиля MAX **ссылкой на профиль/QR** и замените файл `images/qr-max-contact.png` на QR с этой ссылкой; также замените подпись и адрес кнопки в `index.html`. Нельзя получить достоверную персональную ссылку MAX из одного номера телефона.

## 4. Обновление сайта на GitHub Pages

Если у вас **уже есть** репозиторий сайта: замените в нём `index.html`, `README.md` и `apps-script/Code.gs`, затем сделайте **Commit changes**. При работе через терминал в папке вашего существующего проекта используйте `git add .`, `git commit -m "Update site and booking"`, `git push`. **Не выполняйте повторно `git init` и `git remote add`** в действующем репозитории. Откройте сайт через пару минут и обновите кеш страницы.

Если репозитория ещё нет, следуйте инструкциям ниже.

## 5. Первая публикация на GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `magia-prazdnika`, без README.
2. В терминале в папке проекта выполните (подставьте свой логин):

   ```sh
   git init
   git add .
   git commit -m "Add Magiya Prazdnika website"
   git branch -M main
   git remote add origin https://github.com/ВАШ-ЛОГИН/magia-prazdnika.git
   git push -u origin main
   ```

   Без терминала: на странице репозитория нажмите **Add file → Upload files**, перетащите все файлы и папки проекта и нажмите **Commit changes**.
3. В репозитории откройте **Settings → Pages** → **Build and deployment** → **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/magia-prazdnika/`.
5. Обновления: `git add .` → `git commit -m "Update website"` → `git push`.



Трек `assets/jingle-bells.mp3` включается автоматически при загрузке с тихой громкостью. Если браузер блокирует автоматическое воспроизведение со звуком, проигрывание начнётся после первого действия пользователя. Кнопкой с нотой внизу экрана музыку можно выключить или включить.
## Оформление и музыка

Кнопка подбора выделена отдельно на первом экране и украшена ёлочкой; в квизе рядом с вопросом о корпоративе есть краткое пояснение. QR-коды в подвале расположены в одинаковых карточках. Ненавязчивая оригинальная мелодия пытается включиться при входе; если браузер запрещает автозапуск со звуком, она начнётся после первого действия на странице. Кнопка «Выключить музыку» останавливает её и запоминает выбор на этом устройстве.
